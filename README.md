## 四、项目简介

一个记账类 Android 应用，采用暖橙柔系配色，主要功能如下。

**弧形导航栏**
自定义 View 绘制的弧形导航栏，支持拖动跟手、松手吸附、长按进入拖动模式。选中项背后有橙色空心光晕。

**记账页**
金额录入与快捷累加、收支两套独立分类、三列滚轮日期选择（年月日联动，日数随月份自动修正）、账户选择、备注输入。保存前做金额与分类的非空校验。

**账单页**
顶部汇总总支出与总收入，下方用 `ListView` 展示记录列表。支出红色带负号，收入绿色带正号，条目间用浅色细线分隔。

**设置页**
三类备选控件，且每项设置都真实影响其他页面：主题配色改变导航栏选中色、默认账户成为记账页预选项、提醒开关控制首页提示条。

**弹层系统**
从屏幕底部弹出的信息确认弹窗，支持多层嵌套——新弹窗打开时旧弹窗上移并降低透明度，且不可交互。底部按钮采用挖槽设计，支持单按钮（关闭 / 确定）与双按钮（取消 / 确认）两种形态。

**数据持久化**
记账记录以 JSON 形式存入 `SharedPreferences`，关闭应用后数据保留。

## 六、如何运行

1. 用 Android Studio 打开本工程目录；
2. 首次打开会提示配置 SDK 路径，按提示选择本机 Android SDK；
   或手动在工程根目录新建 `local.properties`，写入：
   ```
   sdk.dir=你的Android SDK路径
   ```
3. 等待 Gradle 同步完成后，点击运行按钮，安装到模拟器或真机。

> **注意**：请将工程放在**不含中文字符的路径**下，否则 Android Gradle 插件会拒绝编译。
